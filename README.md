# Librería

Descripción breve del proyecto.

## 🚀 Tecnologías utilizadas

- Python 3
- Django
- HTML / CSS
- Bootstrap

## ⚙️ Instalación

1. Clona el repositorio:

   ```bash
   git clone https://github.com/pablotebb/Libreria.git
   cd Libreria
   ```

2. Crea y activa un entorno virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate  # o venv\Scripts\activate en Windows
   ```
3. Instala las dependencias:
   pip install -r requirements.txt

4. cd Libreria

5. python manage.py makemigrations

6. python manage.py migrate

7. python manage.py createsuperuser

8. Ejecuta el proyecto:
   python manage.py runserver

9. Desde el navegador:
   http://127.0.0.1:8000/admin

10. Nos situamos en Categorias, creamos unas cuantas categorias.
    Ej: Cuento, Novela historíca, Poesía, Novela...

11. Desde el navegador:
    http://127.0.0.1:8000/
    (accedemos ya a la aplicación)

## 📌 Notas

- Este proyecto está en desarrollo / producción.
- Asegúrate de tener Python 3 instalado.
